# 注册用户名校验修复（2026-10-29）

生产注册页面曾将邮箱形式的用户名拒绝为 `string_pattern_mismatch`，并直接展示英文校验消息。网页、APP 和管理端表单也保留了旧的用户名正则。

本次统一账号标识规则：用户名为 3–80 个字符，可使用字母、数字、下划线、短横线，或合法的 ASCII 邮箱格式；长度与既有数据库列及登录接口上限一致，不需要数据库迁移。用户名仍作为登录标识，绑定邮箱用于验证和找回密码，二者不会自动互为登录别名。已有账号标识及密码不做修改。

网页和 APP 源码共用账号校验及中文 API 错误转换。表单在提交前说明用户名要求，服务端仍独立校验。校验错误不回显请求中的密码、验证码或 Pydantic 的 input/context 内容。

注册仍须遵守管理员开关、邮箱验证码、账号与邮箱唯一性及原有频率限制。

验收使用合成账号、隔离数据库及受控 SMTP；生产接口只提交无有效验证码的合成请求，确认邮箱用户名能进入验证码校验，没有创建生产测试账号，也没有请求发送邮件。浏览器验收使用生产域名，不使用截图里的账号、密码或验证码。

本次发布范围为 API、桌面网页及管理端；APP 源码已同步校验规则，公开 APK 保留已经验签的 1.0.4 安装包，新的表单交互将在下次打包后进入安装包。
