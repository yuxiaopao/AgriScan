# APP、桌面与管理配置

## 三个独立入口

| 界面 | 工程 | 本机默认地址 | 登录会话 |
| --- | --- | --- | --- |
| 桌面用户端 | `frontend/` | http://127.0.0.1:5173 | 用户端 sessionStorage |
| 手机 APP 预览 | `mobile/` | http://127.0.0.1:5174 | 按服务地址隔离的本机令牌 |
| 管理控制台 | `admin/` | http://127.0.0.1:5175 | 独立管理员 sessionStorage |

管理控制台采用独立构建、入口和登录。普通成员无法进入，服务端仍对每个管理接口校验角色。桌面旧 `#admin` 链接引导至新入口，用户构建不包含管理界面。三端共享工作空间地块和检测数据；小禾私人会话仍按用户隔离。

启动与停止 APP、管理端：`scripts/start-clients.ps1`、`scripts/stop-clients.ps1`。已有 18000 的 AgriScan API 可复用；端口属于其他程序时保留该进程并报错。数据库容器和上传数据不会随停止脚本删除。桌面开发仍用 `scripts/start-dev.ps1`。本机后端配置为 MySQL + Redis，没有切回 SQLite。

## 管理员可修改的配置

在「系统配置」中编辑后点击「保存所有配置」：

- 品牌：应用名称、介绍、客户端公告。
- 功能：图片、视频、实时相机、小禾新问答、知识与地块入口。
- 限额：图片 1–10 MB、视频 1–50 MB / 1–60 秒 / 1–8 个采样时点，实时请求最短间隔 750–10000 毫秒。
- 账户：开放注册、注册邮箱验证。
- 邮件：SMTP 主机、端口、用户名、发信邮箱、加密方式和授权密码。
- 小禾：模型 API 地址、模型名称、超时、API 密钥、启用状态。
- 模型产物：权重上传上限 1–2048 MB。模型文件登记不等于启用推理，活动模型仍需通过发布校验。

运行配置使用数据库表 `workspace_configuration`（Alembic 05），按版本保存。多位管理员同时编辑时，旧版本保存返回 409，需要读取最新版本后重试。切换管理页面会保留本次设置草稿；刷新时有草稿会先保留，显式「丢弃并重新读取」才覆盖。密钥草稿只在页面内存中存在，不写浏览器存储。

服务端在每个请求读取已提交配置，并为该请求固定快照，避免一次 SMTP/LLM 调用混用两套地址和密钥。客户端刷新、回到前台或进入页面时更新配置；桌面另有 30 秒检查。关闭检测或问答会阻止新操作，历史观察与对话仍可读取。知识/地块入口开关不会删除内容，管理员仍可维护。

「小禾大模型服务」提供 DeepSeek 快速填入和独立「测试连接」。测试分别验证短文本与服务器合成图片，不保存配置或改变开关；确认后仍需明确保存。保留已存密钥测试时，API 地址必须与保存地址一致；更换服务地址需提供对应的新密钥。生产使用情况与实际点击证据见[DeepSeek 接入验收](deepseek-assistant-20261029.md)。

桌面小禾主对话区支持分节、列表、粗体及行内代码的安全文本排版。向上阅读时保持位置，提供「回到最新」；左侧历史菜单与主内容分开，放大和还原窗口后仍可继续对话。

数据库地址、Redis、JWT、管理员初始化凭据、模型发布路径及跨域白名单属于部署环境参数，在后端 `.env` 中维护，改动后重启服务。

## 密钥保管

后台填写的 SMTP / LLM 密钥通过 Fernet 加密后写入数据库，接口只返回「已配置」标志；审计只记录修改的字段名。保留原值时不提交密钥字段；替换时提交新值；清除时显式提交 `null`。

服务器需配置独立的 `CONFIG_ENCRYPTION_KEY`，格式为 `Fernet.generate_key()` 的结果。当前本机已经生成并写入忽略的 `backend/.env`，没有提交或打印该值。必须安全保留这把密钥，数据库迁移时单独迁移；数据库备份中只有密文。恢复数据库但缺失或更换密钥时，服务会明确拒绝解密，避免悄悄丢失配置。不要把密钥写入 `VITE_*`、前端源码或 Git。

## 识别与 APK 范围

图片与媒体根据清单使用真实 ONNX 目标检测或旧分类模型，上传时不需要预选作物。新检测模型提供原图归一化目标框，旧分类模型不输出框；视频按时间采样并保存各时点结果，实时相机串行抽帧，只有用户选择保存才落库。目标框不是病斑精确轮廓，不提供连续追踪或视频每帧覆盖。

APP 界面、Android 工程、原生相机权限/拍照、返回键、IP 图标和构建脚本已提供。`npm run android:sync` 已完成网页构建与原生同步。项目隔离安装了 JDK 21 和 Android SDK 36，系统 Java 17 保留；已实际构建、核验并发布 v1.0.1 / code2 调试签名测试 APK。实际硬件相机、厂商权限和 Android 返回键仍需真机验收。详见 `mobile/README.md`。

小禾图片分析依赖管理员配置的可用大模型服务。外部服务无可用账户或连接失败时，应用显示真实错误和重试，不生成假建议。SMTP 配置保存不代表邮件送达，需要实际可发信的邮箱服务。
