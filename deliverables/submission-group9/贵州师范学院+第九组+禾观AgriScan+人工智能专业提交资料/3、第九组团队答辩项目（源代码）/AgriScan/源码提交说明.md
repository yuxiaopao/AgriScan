# 第九组 禾观 AgriScan 源代码提交说明

本目录为当前工作区的精简源码副本，包含桌面端、移动端、独立管理端、FastAPI 后端、数据库迁移、共享逻辑、训练及部署脚本、依赖锁定与模型元信息。

按提交要求省略测试文件、测试数据、图片与音视频素材、模型权重（PT/ONNX等）、数据集、训练输出、虚拟环境、node_modules、编译缓存、APK、构建产物和实际 .env。原始项目不受影响。

## 目录
frontend/ 桌面 React 工作台；mobile/ React 手机界面和 Android 工程；admin/ 管理端；backend/ API、推理适配与迁移；shared/ 共享规则；training/ 训练与数据整理源码；deploy/ 部署；scripts/ 开发与构建；website/ 官网源码；models/ 类别与模型清单。

## 恢复运行
使用 Python 3.12+、Node.js 22.12+，并准备 MySQL 和 Redis。按根目录及各模块 .env.example 自行创建配置；任何已有账号密码、SMTP授权码、模型服务密钥均未随包提供。依赖安装、启动和 Android 构建步骤见各模块 README 与 scripts/。

本包按要求不含界面图片、IP素材和权重，因此不能直接复现完整视觉或识别效果。需从项目原目录补回各客户端引用的素材、模型文件，并按 manifest 核对版本和哈希。只查看源码不需要这些大文件；运行真实识别则必须提供模型。MODEL_MANIFEST 与 CLASSIFICATION_MODEL_MANIFEST 留空可启动无识别结论的界面与采集模式。Android另需 JDK21、SDK36，构建前安装依赖并执行 Capacitor 同步，生成插件及应用静态资源。
