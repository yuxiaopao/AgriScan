# 作物主题与小禾素材

为现有 17 种作物准备了独立配色，以及小禾手持对应作物的 8 帧观察循环。
素材使用内置 image_gen 生成，以原小禾形象为身份参考；没有通过程序绘制角色或道具。

- 成品：`frontend/public/images/xiaohe-crops/`，每种作物一张 3072 × 416 WebP 动画帧条和一张 384 × 416 静态后备图。
- 原图：`design/xiaohe-crops/source/`。
- 生成提示词及树莓间距修复提示词：`prompts.json`。
- 逐帧检查报告：`frame-review.json`；17 组 × 8 张独立帧，检查透明边距、主体面积及裁切情况。
- 总览：`contact-sheet.jpg`。
- 浏览器验证记录：`browser-checks.json`。

## 行为

模型就绪时无需预选作物：上传叶片并点击识别，模型返回真实作物与病害，页面自动切换对应配色和小禾手持物，并展开小禾照片分析。作物按钮只浏览主题，不限制全类别识别、不改写已有结果或地块关联；刷新后保留主题。无模型时仍用按钮与下拉框选择采集作物。检测请求进行中锁定照片、主题、地块与备注。

支持范围由后端活动模型决定。当前模型支持 14 种作物；水稻、小麦和黄瓜标注“仅主题”，可浏览配色和素材，不能据此增加识别类别。没有模型时只保存手动标注的样本，不虚构自动识别结论。

每种作物使用完整的持物观察循环；检测、思考等状态沿用状态提示并调整动画节奏。设置页仍保留原六种动作的独立预览。关闭界面动效、系统减少动态效果、标签页不可见或角色滚出视口时，停止相应动画。

结果置信度、疾病候选分数与健康/需关注状态颜色保持原有含义。

## 重新打包

运行环境已含 Pillow。打包工具沿用桌宠技能的连通区域分离方式，保留原始 RGBA 像素，统一缩放注册，再编码为 WebP。半透明生成边缘可能连接邻帧，因此用高透明度核心作分割掩码，并检查每一帧的主体面积和安全边距。

```powershell
./backend/.venv/Scripts/python.exe scripts/build-crop-mascots.py --skill-dir "<create-pet 技能目录>"
```

运行网站只需要已保存的成品，不依赖该技能或图片生成服务。
